# Visual sources

The redesigned home hero takes composition inspiration from https://www.taskrabbit.com/ (central search and repair-category navigation). FixMate retains its own copy, branding, palette, layout details, and workflows.

The Services directory draws layout inspiration from the repair-service themes listed at https://themeforest.net/search/repair%20service and the Renovation service showcase at https://renovation.thememove.com/services/: a strong page banner, repair imagery and service-card presentation. FixMate uses its own implementation, green palette, copy and existing licensed photograph; no paid template code or assets were copied. Its filter sidebar, URL-backed categories, active chips and pagination connect to the existing MongoDB API.

`public/images/repair-workbench.jpg`: Samsung Memory on Unsplash, https://unsplash.com/photos/a-woman-sitting-at-a-table-working-on-a-piece-of-electronics-kle_II70cjM, free under the Unsplash License. Downloaded from the image URL exposed by that source, resized to 1400px. Illustrative repair photograph; it does not depict a claimed FixMate employee.

DM Sans and Manrope are self-hosted through their Fontsource variable-font npm packages. Lucide supplies interface icons; the X glyph represents the current platform. Seed service illustrations are separate ImgBB-hosted demo assets.
