From the server directory:

```powershell
npm run seed:demo
# Prints the seed plan without writing data.
npm run seed:demo -- --apply
# Adds missing seed records; keeps existing accounts and edited seed records.
npm run demo:check
# Checks real sign-in/roles/service/booking workflows and unpaid Stripe checkout.
```

The seed script refuses to overwrite reserved emails/IDs belonging to non-seed records, does not reset passwords, and requires `--allow-production` in addition to `--apply` when NODE_ENV=production. Preserve `.env.demo` for reruns; if it is lost, restore it rather than resetting accounts automatically. It creates only the same four application collections plus BetterAuth's authentication infrastructure. Uploaded illustration URLs are cached under the ignored node_modules/.cache directory.
